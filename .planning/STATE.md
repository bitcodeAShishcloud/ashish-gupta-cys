- `npm run build` must not run while `next dev` is active on the same `.next`

## Key Learnings

- XKiro image endpoint is an async job API: POST `/v1/images/generations` → 202 `{id, status}` → poll `GET /v1/images/generations/{id}` → `succeeded` with `data[0].url` on `cdn.xkiro.com` (different host than the API — image fetch must not apply the AI_ALLOWED_HOSTS whitelist, only the SSRF blocklist)
- Client SSE contract: `data: {"delta"}`, `data: {"error"}`, `data: {"done"}`
- Next.js dev-mode react-refresh needs `'unsafe-eval'`; CSP now grants it only when NODE_ENV=development
