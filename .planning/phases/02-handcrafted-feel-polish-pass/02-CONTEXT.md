# Phase 2 Context: Handcrafted Feel Polish Pass

**Phase:** 2 of 2 — Handcrafted Feel Polish Pass
**Date:** 2026-10-31
**Input:** User direction: "sab kuch aisa lage ki AI-generated nahi hai" — copy and visual details must read personal and deliberate.

## Approach

Copy is reframed from "AI assistant product" voice to "message Ashish" voice — honest (it is an assistant) but written like a person set it up. Visual changes are restrained: one deliberate human touch (small avatar beside assistant replies), everything else already matches the custom theme.

## Copy Decisions

| Where | Before | After |
|---|---|---|
| Name gate title | "Who are you?" | "What should I call you?" |
| Name gate desc | "Your name and this conversation stay in your browser…" | "Just a nickname is fine. Your name and this conversation stay in your browser — nothing is stored on a server." |
| Name gate button | "Start" | "Let's go" |
| Greeting | "Hi {name}, what do you want to know?" | "Hey {name} — what are you curious about?" |
| Status line | "Ashish's AI assistant" | "online · replies instantly" |
| Suggestions label | "Try asking" | "Not sure where to start?" |
| Suggestions | generic ("What can you do?") | specific & personal ("What is Ashish good at?", "How was Poppit AI built?", "How do I get started in cybersecurity?", "Which certifications does Ashish have?") |
| Placeholder (page/widget) | "Ask about projects, skills…" / "Ask anything…" | "Type your question…" / "Type a message…" |
| Counter | "{n} of 30 sent today · stays on your device" | "{n}/30 today · stays on your device" |
| Erase dialog | "Erase all local data?" | "Clear this chat?" |
| Widget title | "Ashish's AI" | "Ask Ashish" |
| Home hero button | "Ask the AI" | "Ask Ashish" |
| Contact copy | "ask the AI assistant about my work" | "ask me anything through the chat" |
| Contact button | "Chat with AI" | "Ask Ashish" |

## Visual Decisions

- Assistant replies get a 20px avatar (favicon) aligned to the top-left — reads like a person answering, matches the name-gate logo already in use
- Everything else unchanged: bubbles, spacing, motion already follow the site theme

## Out of Scope

- Any redesign, new sections, or structural changes
- Admin console copy (owner-facing, not visitor-facing)
